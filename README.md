Student Grade Calculator

Project 2

A simple Java application that calculates a student's total marks, average, percentage, and grade based on marks obtained in multiple subjects.

Features

- Accepts marks for multiple subjects
- Accepts marks out of 100
- Calculates total marks
- Calculates average
- Calculates percentage
- Assigns a grade based on percentage
- Displays the result clearly
- Validates marks entered by the user

Technologies Used

- Java
- Scanner
- Variables
- Loops
- Arithmetic Operators
- Conditional Statements

Grade Criteria

Percentage| Grade
90–100| A
80–89| B
70–79| C
60–69| D
50–59| E
Below 50| F

How to Run

1. Save the Java file as "StudentGradeCalculator.java".
2. Open the terminal in the project folder.
3. Compile the program:

javac StudentGradeCalculator.java

4. Run the program:

java StudentGradeCalculator

Sample Input

Enter number of subjects: 5
Enter marks for Subject 1 (out of 100): 85
Enter marks for Subject 2 (out of 100): 78
Enter marks for Subject 3 (out of 100): 92
Enter marks for Subject 4 (out of 100): 74
Enter marks for Subject 5 (out of 100): 88

Sample Output

----- Student Result -----
Total Marks: 417 / 500
Average: 83.40
Percentage: 83.40%
Grade: B
